Renders a single Lucide line icon; use anywhere the kit needs a search glyph, chevron, calendar, pin, etc.

```jsx
<Icon name="map-pin" size={16} color="var(--text-muted)" />
```

Requires `https://unpkg.com/lucide@latest/dist/umd/lucide.js` loaded on the page (see assets/README.md). Common names used across this kit: search, map-pin, calendar, clock, chevron-down, chevron-right, chevron-left, x, check, check-circle, star, ticket, qr-code, image, upload, filter, plus, minus, users, trending-up, alert-circle, arrow-right, more-horizontal, credit-card, shield-check.
